RIMBA MADU - WEBSITE KATALOG MADU

Cara menggunakan:
1. Buka index.html di browser.
2. Klik Admin di kiri bawah.
3. Pada penggunaan pertama, masukkan kode akses minimal 6 karakter untuk membuat kode lokal.
4. Tambahkan/edit/hapus produk, unggah foto, ubah nama toko atau nomor WhatsApp.
5. Tombol Pesan Sekarang otomatis membuat pesan WhatsApp sesuai produk.

PENTING: Ini versi demo statis. Produk dan kode admin disimpan dalam localStorage browser, sehingga perubahan TIDAK tersinkron antar perangkat/pengunjung. Kode akses lokal BUKAN sistem autentikasi yang aman untuk website publik. Untuk toko produksi perlu backend, database, penyimpanan foto cloud, dan autentikasi server.
